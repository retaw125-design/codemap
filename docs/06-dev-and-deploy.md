하루 6~8시간, 주 5일 기준 4주(20일). 금요일은 버퍼, 주말은 휴식 또는 추가 버퍼.

## CI/CD (GitHub Actions)
작업 브랜치에 올릴 때마다
1. 백엔드·프론트엔드 테스트
2. 린트와 타입 검사
3. 공용 테스트 케이스를 양쪽에서 실행해 결과 일치 확인
4. 자동 생성 타입이 최신인지 확인
5. 키 유출 검사
하나라도 실패하면 합칠 수 없다. AI 에이전트의 코드도 같은 관문을 통과한다.

main에 합쳐지면 백엔드는 Railway, 프론트엔드는 정적 호스팅으로 자동 배포.
매주 평가셋·문제 데이터 백업.
